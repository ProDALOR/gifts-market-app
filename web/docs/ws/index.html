    How the stream works

    • subscribe starts a live page using an ID. Unsubscribe before reusing an ID. unsubscribe releases it without an acknowledgement.
    • page replaces the requested page. Use the frame-level sync for current freshness.
    • sync leaves orders unchanged. A changed revision can invalidate continuation pages even when the head stays the same.
    • Use HTTP /orders/query with the same query and consistency: live to load more. Execution history uses /history/query.
    • Browsers answer WebSocket pings automatically. After a disconnect, reconnect with backoff and resubscribe. This console connects only on demand and closes when you leave.
    • Slow consumers close with code 1013. Error frames include a subscription ID, or an empty ID for connection-level errors.
    • watch_catalog watches catalog revisions for up to eight collections. Compare catalog frames with HTTP ETag headers to reload changed choices without polling. Reconnects send the complete current revision set.
